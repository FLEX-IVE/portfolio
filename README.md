# Portfolio Starter

A simple portfolio website template designed for GitHub Pages and easy editing.

## Files

- `index.html` — page structure
- `style.css` — theme, layout, and responsive styling
- `script.js` — dark/light theme toggle logic

## Customize

Open `index.html` and replace the placeholder content with your own:

- Name and headings
- About text
- Skills
- Projects
- Contact email and links

## Preview locally

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Deploy to GitHub Pages

1. Push this project to a GitHub repository.
2. In GitHub, open the repository.
3. Go to Settings > Pages.
4. Under Source, choose "Deploy from a branch".
5. Select the `main` branch and the root folder (`/`).
6. Save.

GitHub will provide a live URL for your portfolio.

## Theme toggle

The site includes a dark and light mode switch that saves the chosen theme in local storage.
